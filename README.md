# 246Competitions

246Competitions is a web application where users can enter to win amazing prizes like cars, cash, and more! The platform hosts various competitions, each with a chance to win exciting rewards. Users can easily view and enter competitions with just a few clicks.

## Features

- **Enter Competitions**: Users can browse competitions for a chance to win various prizes.
- **Guaranteed Winners**: Every competition has a guaranteed winner, drawn live.
- **Secure and Fair**: All draws are independently verified and recorded.
- **Exciting Prizes**: From luxury cars to huge cash prizes, we offer the best rewards.
- **Responsive Design**: Optimized for both desktop and mobile use.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **Lucide Icons**: For vector icons such as the trophy icon.
